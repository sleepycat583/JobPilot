## 覆盖范围

案例使用合成文本，不包含真实简历、JD、用户对话或任何凭据，覆盖：

- 简历解析、内容表达和具体版本创建
- JD 解析、JD 追问和面试重点
- 直接匹配、指代匹配、评分和匹配方法咨询
- 面试开始、回答、继续、跳过、结束和已有上下文
- 闲聊、通用职业建议、资料不足和从已结束面试切换主题

## 复现命令

在本地完成模型认证后，从 `backend` 目录运行：

```powershell
.\.venv\Scripts\python.exe -u .\scripts\evaluate_supervisor_routes.py
```

命令只打印合成案例 ID、Worker 名称和统计指标。可用 `--json-output` 写出只含案例 ID 和路由结果
的脱敏汇总，不会把案例正文、模型 payload、trace 内容或凭据写入报告。

## 结论与限制

本次结果证明当前 prompt 和状态上下文在这组固定合成案例上达到阶段门禁，不代表所有自然语言输入
都能保证 100% 路由正确。后续应持续把经过脱敏的真实失败样本加入评测集，并在每次 prompt、模型或
Worker 边界变更时重新运行该门禁。
